使用 Hexo 快速搭建个人博客

Hexo中文文档
Hexo 是一款基于 Node.js 的静态博客框架，轻量、高效，无需数据库，生成的静态页面加载速度快，非常适合搭建个人技术博客。本文将带你从 0 到 1 完成 Hexo 博客的搭建、自定义和部署。

一、环境准备

安装Node js

所需的版本请根据hexo的官网选择，一般来说，直接去官网安装最新版本的即可
Node js中文官方网站

安装git

如果您需要将自己的个人博客部署到GitHub让其他人能够访问呢，就需要安装
git 安装教程中文版

二、安装 Hexo 并初始化博客

ps. 建议按照官方网站的教程进行安装，那里的教程始终是最新的

使用npm安装hexo-cli

安装完hexo后，请选择一个文件夹作为自己博客项目的地址，在命令行进入该地址后，请执行下列命令

之后您会看到很多文件（夹），比较重要的是

  1. _config.yml 这是项目的配置文件，可以根据官方网站自行配置 hexo 配置
  2. scaffolds文件夹，这里存放的是模板文件，里面一般会修改post.md，这样下次新建新的文章的时候就会按照这里的模板创建新的文件。
  3. source文件夹 资源文件夹。 是存放用户资源的地方。

使用hexo

大部分的命令可以有其他参数，详情可以访问hexo 命令介绍

new命令

默认会生成一个新的文章。

generate

生成静态文件。

server

启动服务器。 默认情况下，访问网址为： http://localhost:4000/

deploy

部署你的网站。需要先生成静态网站。

clean

清除缓存以及删除静态文件。

主题以及部署

部署到GitHub有官方的教程，主题一般也都有自己的使用教程，我使用的是 Async主题 里面也有部署的教程，因此不细说。
